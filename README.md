실제 2048 전략처럼 큰 숫자를 
구석에 밀어넣도록 설계되었으며, 이를 위한 여러 변수들이 설정되어있습니다.

핵심변수 2가지만 소개하겠습니다.
score(b): 현재 보드의 점수를 계산하는 휴리스틱(Heuristic) 함수입니다.
빈 칸의 개수 + 최대 타일 값 $\times$ 0.01
빈 공간이 많을수록 유리하다고 판단합니다.

ai(b): 상·하·좌·우 4가지 이동 결과 중 score 점수가 가장 높은 방향을 선택하여 움직인 후 새 타일을 생성합니다.
